INFLOW DEFAULT REDESIGN · EMIL KOWALSKI MOTION STANDARDS

InFlow Default · 呼吸波

針對創辦人即時反饋：「Listening 後面冇了三個點點」、「六條 bar 變成三點硬吃不動」、「綠色的燈應該變成呼吸燈」的完整修復與進階動態實現。

即時互動畫布（直接模擬按住 Option 及語音波動） 狀態：listening

🟢 綠色呼吸燈（Breathing Light）

採用 1.6s 平滑循環呼吸（cubic-bezier(0.4, 0, 0.2, 1)），核心原點伴隨外暈光環律動，呈現「正在持續聆聽」的真實生命感。

⋯ Listening 動態三點（Ellipsis）

標籤緊隨三顆以 180ms 錯開淡入淡出的白色脈衝圓點，即使尚未說話，視覺亦隨時保持前進動力，絕無呆滯感。

📊 6 條活體音波（Waveform Bars）

垂直置中展開，待機時具備微幅海浪起伏（Idle wave），開口時以 Fast Attack (0.6) 及 Smooth Release (0.15) 即時隨語音跳動，告別「硬吃不動」。

採用技能與動態工程規範（Skills & Motion Standards）

emilkowalski/skills
Emil Kowalski 設計工程指南 (emil-design-eng)：遵循 Vercel / Linear 等頂尖產品動畫標準，核心關注非對稱進退場、自然曲線與無延遲反饋。
Fast Attack / Decay
非對稱音訊反應包絡：attack: 0.6（瞬間咬住語音音量峰值）、decay: 0.15（平滑緩慢釋放回落），消弭傳統音量條突兀跳動（Jitter），令音波起伏如呼吸般柔和。
Phase-Shifted Wave
待機活體波算法：採用多相位正弦曲線 Math.sin(t * 2.2 + i * 0.85) * 0.08 + 0.18。在靜音或等待發聲期間，6 條波柱持續維持 4~6px 的緩慢流動，徹底根治「硬吃不動」如同當機的誤解。
Staggered Ellipsis
錯開微動態脈衝：每顆點點以 180ms 延遲錯開 keyframe opacity 動畫，在靜止文字中注入持續向前的運作感。
Hardware-Accelerated
離線合成器硬體加速：所有波形更新均採用純 transform: scaleY() 與 will-change: transform，脫離主執行緒（Off-main-thread），不觸發 Layout / Reflow，確保維持穩定 60fps。
