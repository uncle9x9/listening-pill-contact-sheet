INFLOW DEFAULT REDESIGN · EMIL KOWALSKI MOTION STANDARDS

InFlow Default · 呼吸波

針對創辦人即時反饋：「Listening 後面冇了三個點點」、「六條 bar 變成三點硬吃不動」、「綠色的燈應該變成呼吸燈」的完整修復與進階動態實現。

即時互動畫布（直接模擬按住 Option 及語音波動） 狀態：listening

🟢 綠色呼吸燈（Breathing Light）

採用 1.6s 平滑循環呼吸（cubic-bezier(0.4, 0, 0.2, 1)），核心原點伴隨外暈光環律動，呈現「正在持續聆聽」的真實生命感。

⋯ Listening 動態三點（Ellipsis）

標籤緊隨三顆以 180ms 錯開淡入淡出的白色脈衝圓點，即使尚未說話，視覺亦隨時保持前進動力，絕無呆滯感。

📊 6 條活體音波（Waveform Bars）

垂直置中展開，待機時具備微幅海浪起伏（Idle wave），開口時以 Fast Attack (0.6) 及 Smooth Release (0.15) 即時隨語音跳動，告別「硬吃不動」。
